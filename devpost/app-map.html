ScopeGuard Architecture Map

Deterministic AI Collateral-Damage Firewall & Surgical Code Splicer.

Architectural Code Tour

Stop 1 • The Contract
src/types.ts
Defines the strongly typed DiffHunk and HunkClassification models: AUTHORIZED, COLLATERAL_MUTATION, SCOPE_CREEP, and INVARIANT_BREACH.
Stop 2 • Line & Hunk Differ
src/engine/differ.ts
Deterministic Myers / Longest Common Subsequence (LCS) line diff algorithm that extracts contiguous addition/deletion hunks with 100% precision.
Stop 3 • Structural Symbol Scanner
src/engine/astScanner.ts
Fast lexical AST parser that resolves the exact enclosing symbol (function, React component, CSS rule, interface) for every diff hunk.
Stop 4 • Intent & Scope Classifier
src/engine/classifier.ts
Compares proposed modifications against the developer's original prompt. Automatically catches unrequested layout breaks, silent error deletions, and ghost dependencies.
Stop 5 • Surgical Splicer
src/engine/splicer.ts
Reconstructs clean, production-ready code by splicing only accepted hunks and perfectly preserving untouchable original code.
Stop 6 • Workbench & Concordance Ring
src/main.ts
Drives the Apple-Pro dark UI, SVG Concordance Ring purity gauge, interactive hunk cards, custom code audit modal, and unified .patch exporter.

Deterministic Execution Pipeline

Original Code + AI Proposed Code + Developer Prompt │ ▼ [1] computeLineDiff() ──▶ Myers / LCS Line & Hunk Extraction (src/engine/differ.ts) │ ▼ [2] resolveEnclosingSymbols() ──▶ Lexical Enclosing Symbol Resolution (src/engine/astScanner.ts) │ ▼ [3] classifyHunks() ──▶ Scope Guardrail & Intent Verification (src/engine/classifier.ts) │ ▼ [4] Concordance Ring Telemetry ──▶ Purity Score & Collateral Radar Readouts (src/main.ts) │ ▼ [5] Surgical Remediation ──▶ Master "Purge Collateral" / Per-Hunk Toggle (src/main.ts) │ ▼ [6] spliceSource() ──▶ Reconstructed Clean Code & Unified .patch Export (src/engine/splicer.ts)

A Practice to Reuse

Deterministic AST Verification Over Secondary LLM Inferences
When building safety and compliance layers for generative AI, resist the temptation to call another LLM to verify the first LLM's output. Second-order LLM calls introduce network latency, nondeterministic hallucinations, and API bill shock.

ScopeGuard demonstrates the architectural pattern of Deterministic Guardrails: use dynamic programming (Myers LCS differ) and lightweight lexical AST grammar parsers to extract mathematical truths about code mutations in under 2 milliseconds, client-side, with zero external dependencies.
Reproducibility: Run npm install && npm run dev for local server (port 5173), or npm test to run the automated Vitest suite.
