ScopeGuard Architecture Map

Deterministic AI Collateral-Damage Firewall & Surgical Code Splicer.

Architectural Code Tour

Stop 1 • The Contract
src/types.ts
Defines the strongly typed DiffHunk and HunkClassification models: AUTHORIZED, COLLATERAL_MUTATION, SCOPE_CREEP, and INVARIANT_BREACH.
Stop 2 • Line & Hunk Differ
src/engine/differ.ts
Deterministic Myers / Longest Common Subsequence (LCS) line diff algorithm that extracts contiguous addition/deletion hunks with 100% precision.
Stop 3 • Structural Symbol Scanner
src/engine/astScanner.ts
Fast lexical AST parser that resolves the exact enclosing symbol (function, React component, CSS rule, interface) for every diff hunk.
Stop 4 • Intent & Scope Classifier
src/engine/classifier.ts
Compares proposed modifications against the developer's original prompt. Automatically catches unrequested layout breaks, silent error deletions, and ghost dependencies.
Stop 5 • Surgical Splicer
src/engine/splicer.ts
Reconstructs clean, production-ready code by splicing only accepted hunks and perfectly preserving untouchable original code.
Stop 6 • Workbench & Concordance Ring
src/main.ts
Drives the Apple-Pro dark UI, SVG Concordance Ring purity gauge, interactive hunk cards, custom code audit modal, and unified .patch exporter.
